Questions, answered.

Still unsure? Open an issue on GitHub.

Are my documents uploaded anywhere?

No. Everything is processed on your own machine. There is no cloud conversion API and no API key.

Will it always make files smaller?

Not always. Short, already-clean documents can grow slightly because Markdown adds structure. Savings come from removing repeated headers and footers, duplicates, empty cells and layout noise.

Do I need OCR?

Only for scanned PDFs and images. Install Tesseract and TOKENFORGE detects it automatically.

Which formats are supported?

PDF, PPTX, DOCX, XLSX, CSV, TXT, PNG, JPG, JPEG and TIFF.

Which AI tools can I use the output with?

The output is plain Markdown, so you can paste it into ChatGPT, Claude, Gemini, NotebookLM or any other tool.

Is it free?

Yes. TOKENFORGE is open source and released under the MIT License.
